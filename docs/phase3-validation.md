# 第三阶段交付：双赛道与赛事奖牌

日期：2026-10-01。入口：[开发版](http://localhost:5174) / [生产预览](http://127.0.0.1:4176)。

## 本阶段内容

- 新增 **落日峡谷**：约 1.13 km 的独立闭合路线，连续回头弯与缓坡、暖色天空、分层砂岩台地、棕榈与岩石装饰。原有约 0.82 km 的 **海风环线**继续可选。
- 主菜单赛道卡片打开双路线选择，展示长度、特点及奖牌门槛；场景、出生点、护栏、AI、复位、24 个有序检查点、地图和结算均使用同一赛道对象。
- 快速竞速按名次授予金/银/铜牌；计时按三圈总用时授奖。结算显示本场奖牌、下一个目标以及刷新最佳总用时/单圈的提示。
- 最佳总用时、单圈与奖牌按 **赛道 × 模式**分开保存。个人纪录可筛选，保存最近 30 场，超出历史上限仍保留最佳成绩。
- 旧版无赛道字段的纪录归入海风环线；旧设置默认海风环线。新增存档键 `coastline.records.v2`，保留原 `coastline.records` 备份；已有 v2 时优先使用新版。
- 切换赛道时释放物理世界、渲染资源、WebGL 上下文及监听器，移除旧开发接口；旧实例晚到的模型结果会被释放。初始化复用 Rapier Promise；连续完赛采用同步成绩引用，避免 React 批处理覆盖记录。
- 补充 1280×720 布局调整，教学入口与底部卡片不再重叠。

本轮沿用 Classic 赛车和已有 Rodin 模型，没有新增付费生成任务。

## 奖牌门槛

| 赛道 / 计时三圈 | 金牌 | 银牌 | 铜牌 |
| --- | --- | --- | --- |
| 海风环线 | ≤ 1:40 | ≤ 2:00 | ≤ 2:30 |
| 落日峡谷 | ≤ 2:20 | ≤ 2:50 | ≤ 3:30 |

竞速：第 1 名金牌、第 2–3 名银牌、第 4–6 名完赛铜牌。计时超过铜牌门槛仍保存成绩并展示下一目标。峡谷门槛结合本轮自动驾驶基准调整，人工试玩后仍可继续调参。

新增纯函数测试覆盖双赛道中心线/车道投影、起终点接缝、地图边界、非相邻路段间距、三圈有序检查点、奖牌边界、四组纪录隔离、30 场截断后最佳持久化、旧存档迁移及异常数据。

延迟加载专项测试拦住首个棕榈请求，确认切换后的峡谷已建立程序场景、开始按钮可用，再放行模型请求，验证最终开发接口、场景与资产计数仍属于峡谷且只有一个主画布。Three.js 会合并同 URL 的进行中请求，验收按这一实际加载行为设计。

自动驾驶平均三圈用时：海风轻松约 127.68 秒、普通约 101.35 秒；峡谷轻松 **199.43 秒**、普通 **159.52 秒**。这是确定性物理回归，不代表人工驾驶体验或奖牌难度已定稿。

## 实际比赛性能

使用 `node scripts/benchmark-race.mjs canyon`：本机 Chrome 149.0.7827.54 无头浏览器，1920×1080、deviceScaleFactor=1、普通难度、六辆赛车，两档画质分别进行 40 秒实时物理和渲染采样。采样期间不执行加速仿真、不修改业务代码。

| 画质 | 平均 FPS | P95 帧间隔 | >33.34 ms 帧 | 平均绘制调用 |
| --- | ---: | ---: | ---: | ---: |
| 精致 | 120.01 | 9.3 ms | 0 / 4,801 | 128.8 |
| 流畅 | 120.00 | 9.2 ms | 0 / 4,801 | 128.8 |

同环境空白页基线为 120.34 FPS。本机样本达到 60 FPS 数值目标，无运行/WebGL 错误；浏览器自动请求 `favicon.ico` 的 404 单独记作资源提示。采样位于峡谷第一圈第 2–42 秒，包含远端 AI LOD 切换，但没有有效漂移帧；漂移与特效容量由既有专项测试覆盖，本次不是持续漂移压力测试。

数据保存于 [峡谷实际比赛性能](performance-phase3-race.json)。帧率仅代表本机该环境，不推断其他硬件表现。
