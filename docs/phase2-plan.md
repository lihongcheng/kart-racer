# 第二阶段：驾驶反馈与渲染打磨

范围承接首个可玩版本及 Classic 赛车重做，优先完善现有单机竞速。继续沿用海风环线与键盘操作。

## 交付

1. 高速转向随速度适度减弱，并在固定物理步中渐进响应按键；保持 A/左键向左、D/右键向右。小喷只在有效漂移后主动释放时触发。
2. HUD 显示小喷准备进度、松开提示，并区分小喷与氮气。镜头平滑跟随，关闭镜头效果后保持稳定视野。
3. 漂移烟雾、火花与胎痕采用固定容量实例池；暂停时停止车轮和特效计时，重赛时清空。
4. 对重复路面标记、起点格与 Rodin 场景模型做分区实例化。远处 AI 切换保持 Classic 轮廓的低面数版本，近景与车库保留精细模型。
5. 补充有针对性的驾驶、暂停、特效容量、LOD 与实例变换测试；保持十局完赛回归，记录同条件优化前后渲染开销、实际比赛帧率与截图。

## 验收与边界

- 复用同一浏览器、1920×1080、同一空白页基线。通过 `scripts/benchmark.mjs` 比较静止菜单与起跑线场景，避免混入路线差异。
- 目标是减少重复绘制、远景三角形与持续漂移的对象分配；FPS 只报告实测，不从几何计数推断。
- 自动化验证转向方向、渐进输入、漂移与小喷边界、暂停/重赛、两档 AI 完赛、设置及静态发布。
- 人工驾驶手感与声音听感仍需要实际试玩反馈。更多赛道、触控、幽灵车、道具赛和联网分别安排在后续阶段。

## 完成记录

五项交付均已实现并验证。27 项测试、5 组浏览器验收及十局完赛回归通过；同条件菜单/起跑线绘制调用减少约 39% / 41%，本机无头 Chrome 两档 1080p 实际比赛各 40 秒均约 120 FPS。完整范围、测试边界与原始数据见 [第二阶段验收](phase2-validation.md)。
